# 青禾掼蛋 · CherryIN 多厂家模型网页版

支持离线规则 Agent 或 CherryIN 多厂家大模型，保留四方围桌、竖排理牌和暂停/中断续玩。仓库为 [renli19670413/Qinghe-Guandan-AI](https://github.com/renli19670413/Qinghe-Guandan-AI)。[GitHub 发布步骤](PUBLISHING.md) 包含手机在线使用与 Release 下载包说明。

## GitHub Pages 手机在线版

网址：[打开 CherryIN 掼蛋牌桌](https://renli19670413.github.io/Qinghe-Guandan-AI/)。手机固定为横屏牌桌，竖握时画面自动旋转，请横握游玩。顶部“主屏幕游玩”提供安装或添加到主屏幕入口，从图标打开使用独立全屏；菜单中仍可选择普通浏览器全屏，但会出现浏览器自身的安全提示。菜单顶部填写自己的 CherryIN API Key，点“使用密钥”，选择 CherryIN 大模型、厂家、模型、难度，再应用设置。不需要电脑开机或 ChatGPT 登录。

密钥只保存在当前页面的内存，直接通过 HTTPS 发送给 CherryIN；不上传 GitHub，不写浏览器存档。刷新后重新填写，退出前可清除密钥。使用者需信任站点当前源码及其维护者，并在 CherryIN 控制台限制令牌额度。

Pages 使用 CherryIN 的 Messages 兼容接口调用各家文本模型，以适配其跨域鉴权；不能在 Pages 上切换底层接口。已用四家内置示例模型验证一次合法出牌；其他模型是否支持此接口取决于 CherryIN。模型错误会暂停，支持重试或换模型。本机版及独立云端版仍保留原接口选择。

每页最多 200 次生成请求，刷新后计数重置，不是账单限额。存档在同一浏览器中保存，不跨设备同步。手机网络须能访问 GitHub Pages 与 CherryIN；若平台改变跨域配置，页面会显示连接错误，需要适配后才能继续大模型模式。

## 本机版

1. Windows 下双击 `StartWeb.cmd`，或在项目目录运行 `node server.js`（Node.js 22 或更新版本）。
2. 打开 [本机牌桌](http://127.0.0.1:8765/)。默认是离线规则模式，不需要 API 密钥。
3. 使用 CherryIN：在本机设 `CHERRYIN_API_KEY` 环境变量，或复制 `cherryin.config.example.json` 为 `cherryin.config.json`，填入自己的 `apiKey`。不要把密钥发到聊天中。密钥仅由本机服务读取，不进网页或浏览器存档。旧的 `OPENAI_API_KEY` 和 `openai.config.json` 不会被读取，避免将旧平台密钥发送给 CherryIN。
4. 打开「菜单 → AI 决策方式」，选择「CherryIN 大模型」，依次选择厂家、模型、难度，再点「应用 AI 设置」。三家共享本次选择，但各自只读取自己的手牌及公开信息，决策记录按座位隔离。

## 厂家、模型与接口

内置 OpenAI、Anthropic、Google、DeepSeek 四组官方文档示例。选择厂家会联动模型列表。示例不代表当前可用或你的令牌有权限，请以 [CherryIN 控制台](https://open.cherryin.ai/) 的模型列表为准。

点击「刷新 CherryIN 模型列表」会用本机密钥请求 `/v1/models`，将返回的完整 ID 按厂家分类。此操作不是生成请求，不计入游戏的 200 次生成请求上限。部分令牌或服务不开放该列表，失败后仍可使用「自定义模型 ID」。选择「其他厂家」可填写列表外的厂家，模型 ID 必须包含完整前缀，例如 `anthropic/claude-sonnet-4.5`。刷新列表可能包括图片、语音、嵌入等专用模型，游戏仅适用于能返回文本决策的模型。

按 [CherryIN 官方接入文档](https://docs.cherryin.ai/en/docs/newapi/demo-code-usage/)，默认 Base URL 为 `https://open.cherryin.net/v1`，虽然用户控制台在 `.ai`。配置也允许 `https://open.cherryin.ai/v1`；必须与控制台提示一致，不要重复加 `/v1`。为保护密钥，服务只接受这两个官方 HTTPS 域名，不跟随重定向。

接口「自动选择」将 OpenAI GPT-5 及后续系列和 o 系列路由到 Responses，其余走 Chat Completions；可手动覆盖，具体以 CherryIN 对该模型的接口支持为准。不会自动重发或切接口，避免重复计费。不同厂家支持的参数不同，因此不强加 OpenAI 专属推理参数或 JSON Schema；模型得到严格 JSON 提示，返回后由本机验证格式及合法出牌，错误就暂停。

| 难度 | 策略 |
| --- | --- |
| 入门 | 当前牌、少量近期历史，基础策略，较小输出预算。 |
| 标准 | 较多近期历史和自身决策，关注搭档配合及控制牌。 |
| 高手 | 更多历史和公开记牌，提示进行末盘推演，更大输出预算，可能更慢。 |

难度改变模型信息量、策略提示和输出预算，不改变规则，也不保证每种模型下的胜率严格递增。模型本身的思考模式取决于 CherryIN 对该模型的配置。大模型从规则引擎给出的候选中选牌或还牌，游戏再校验；搭档压住时默认让牌，能一次走完可接。API 错误会停在当前回合，可点「重试 AI」，也可切厂家、换模型、降低难度或改用离线。玩家自己的托管仍使用本地规则。

CherryIN 模式会把当前 AI 手牌和公开牌局发送给 CherryIN 及其所路由的模型，并按平台和所选模型计费。令牌分组必须与模型权限匹配。每次启动服务默认最多 200 个生成请求（包括上游失败），在 `cherryin.config.json` 修改 `maxCalls`；次数限制不是金额限制。菜单显示计数。刷新网页后先显示继续入口，不自动调用模型。应用只监听 `127.0.0.1`；若 8765 已被旧版占用，先关闭旧服务，或设置 `GUANDAN_PORT` 后重新启动。

## 竖排手牌与理牌

发牌后，手牌按印刷点数 2 至 A、小王、大王从左到右排列（级牌仍按印刷点数显示，不改变出牌时级牌大小规则）。同点数叠成一列，按黑桃、红桃、梅花、方块由上到下放置；两副相同花色的牌相邻。

选中一组牌后点击「理牌」，只要构成合法牌型，就会独立竖排至最右边。不要求它能压过桌上当前牌，可提前整理顺子、三带对、炸弹等。所选牌不是合法牌型时会提示且不改变位置。「按点数」或「重置理牌」拆开手动分组并恢复默认竖排。已打出的牌自动从分组中移除，新一副重新排序。

## 退出与继续

顶部「退出」会先冻结牌局并取消正在等待的模型请求，再显示两种方式：

- **暂停退出**：保存四家手牌、当前压牌、行动顺序、游数、未完成的贡还牌、手牌分组、选牌、模型设置及各座位自己的决策记录。下次进入点击「继续当前牌局」即可续玩。
- **中断退出**：当前副不计胜负、不升级，仅保留双方级数与本副级牌。下次进入点击「重新发牌，进入游戏」，四家重新发 27 张牌。这次重新发牌不基于被中断副产生贡还牌。

选择退出后保存并离开牌桌，尝试关闭窗口；浏览器禁止脚本关闭时替换为空白页，不再回到继续游戏入口。下次重新打开游戏网址才显示继续入口。网页不能强制终止浏览器应用进程。取消退出立即恢复当前牌局。存档只在当前浏览器、本机同一个网址（含端口）中保存；清理浏览器数据会丢失。存储失败会阻止退出并给出提示。保存不包含 API Key，服务重启后仍需保留本机密钥配置。

## 手机布局（1.4.3）

参考 Qoder 版的横屏构图：顶部精简比分，四方座位围桌，右侧固定操作，手牌列按屏幕宽度和叠牌数量自动缩小并底部对齐。窗口较矮时压缩手牌区，保留牌桌和所有出牌按钮。电脑桌面继续使用原有布局。支持刘海安全区域。

网页不能在未点击时自动隐藏普通浏览器的地址栏。点击“全屏”后会请求横屏锁定，浏览器拒绝时保留可旋转的横屏牌桌并给出添加到主屏幕的说明。主屏幕入口通过 manifest 声明全屏横屏，不提供离线模型服务。

1.4.3 手机布局：玩家状态及最近出牌移到左下角，手牌预留状态区后整体靠右排列；“取消选择”仅取消选牌，不会删牌、重置理牌或重新开局。

1.4.3 手机牌桌：当前压牌、轮到谁和选牌提示统一放到上方出牌区与手牌区之间的中央空白处，提示不再受固定高度裁切；牌型选择菜单仍可操作。

1.4.3：手机顶部改为主屏幕游玩入口，避免反复触发浏览器原生全屏提示；原生全屏仍可在菜单中选择。暂停/中断先保存，随后关闭窗口；浏览器禁止脚本关闭时替换为空白页，不再留在游戏继续入口。下次重新打开网址才能恢复。网页不能终止浏览器应用进程。
